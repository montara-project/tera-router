# @tera/docs

Docs site: TanStack Start + Fumadocs (MDX macro API), deployed to Cloudflare Workers.

- Wiring lives in `src/`: routes in `src/routes/`, loader in `src/lib/source.ts`,
  i18n in `src/lib/i18n.ts` (en-US unprefixed, id-ID under `/id-ID`).
- `src/routeTree.gen.ts` is generated by the TanStack Vite plugin on `dev`/`build`
  — never edit; `typecheck` needs one `vite build`/`vite dev` run first.
- Deploy: `pnpm --filter @tera/docs deploy` (wrangler, config in `wrangler.jsonc`).

See `.zcode/skills/fumadocs/` for the full wiring guide.
