Dashboard (`apps/web-ui`) adalah satu-satunya tempat kamu mengelola router sehari-hari. Semua halaman di bawah ini memanggil REST API server yang sama — kalau lebih suka otomasi, semuanya bisa dipanggil langsung (lihat [API Reference](/docs/api-reference/dashboard-api)).

## Overview

- **Dashboard** — ringkasan traffic, spend, dan performa routing dalam satu layar.

## Traffic

- **Endpoints** — cara menghubungkan aplikasi: base URL + API key, plus setup tunnel untuk dibagikan.
- **Chains** — susun rantai model: langkah berurutan, strategi (`priority`, `round-robin`, `load-balanced`), dan fallback.
- **Skills** — potongan prompt yang bisa dipakai ulang, plus *reference skills* yang bisa dicopy ke coding agent agar paham cara memakai router.

## Connections

- **API Keys** — buat, batasi model, nonaktifkan, dan reveal key `sk_tr_`. Tiap key bisa diikat ke plan.
- **Providers** — hubungkan akun provider (API key atau OAuth), atur prioritas, uji koneksi, dan lihat kuota per akun.
- **Media** — katalog provider untuk embeddings, TTS, STT, dan image.
- **Proxy Pools** — kelompokkan proxy outbound untuk akun yang butuh IP tertentu.

## Safety

- **Guardrails** — kebijakan PII, prompt injection, topik, toksisitas, dan bias, berlapis dari global sampai per-key. Ada mode uji coba (dry run).
- **Provider Health** — kondisi tiap akun provider: cooldown, kegagalan, dan status kuota.

## Cost & Analytics

- **Usage** — request, token, biaya, dan latensi per rentang waktu (hari ini, 24 jam, 7 hari, 30 hari), dipecah per model dan per klien (Claude Code, Cursor, Codex, dll).
- **Plans** — template batas: spend, token, periode, alert, hard cutoff, dan allowlist model.
- **Quota Tracker** — pemakaian terhadap budget yang aktif, bisa dijeda per item.
- **System** — metrik host dan proses server.
- **Settings** — perilaku router: timeout, round-robin provider/chain, proxy outbound, perekaman detail request, sampai branding tampilan.

## Developer

- **Console Log** — aliran log server terbaru (ring buffer 500 entri).
- **CLI Tools** — konfigurasi satu klik untuk coding tools (Claude Code, Cursor, dan lainnya) yang langsung mengarah ke instans Tera Router ini.

<Callout type="idea" title="Satu halaman, satu konsep">
  Kalau baru pertama kali: mulai dari **Providers** (hubungkan akun), lalu **API Keys** (buat akses), lalu **Endpoints** (sambungkan aplikasimu). Sisanya menyusul sesuai kebutuhan.
</Callout>
