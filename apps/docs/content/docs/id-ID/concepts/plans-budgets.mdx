## Plans — template batas

Plan adalah kumpulan batas yang bisa diikat ke banyak key sekaligus. Setiap batas berlaku untuk tiap key sendiri-sendiri: dua key di plan $50 masing-masing bisa memakai $50.

- `budget_spend` — batas biaya (USD) per periode.
- `budget_tokens` — batas token per periode.
- `period` — `daily`, `weekly`, atau `monthly`.
- `alert_at_percent` — persen pemakaian saat halaman Plans menandai key dengan kuning (merah begitu batas habis).
- `hard_cutoff` — apakah batas benar-benar memblokir atau hanya mengingatkan.
- `allowed_models` — allowlist model untuk semua key di plan ini.
- `rpm`, `tpm`, `concurrent` — request per menit, token per menit, dan request yang sedang berjalan per key. Ditegakkan selama **Enforce API key rate limits** (Settings → Network) menyala; request yang melewati batas mendapat `429` dengan `Retry-After`. TPM menghitung token dari request key itu yang sudah selesai dalam satu menit terakhir. Penghitungnya ada di proses server, jadi tiap instance menegakkan sendiri.

Plan _Default_ dibuat otomatis saat seeding. Kelola dari halaman **Plans**.

## Budgets — pemantauan per scope

Budget bekerja di tiga scope, dan masing-masing hanya menghitung trafiknya sendiri: `tenant` (semua request), `api_key` (request yang memakai key itu), dan `account` (request yang dilayani provider account itu). Budget `tenant` atau `api_key` dengan `hard_cutoff` yang terlampaui menjawab `402`. Budget `account` dengan `hard_cutoff` yang terlampaui mengeluarkan account itu dari routing sampai periode reset, sehingga request fallback ke account lain dari provider itu atau ke target berikutnya. Budget tanpa `hard_cutoff` hanya memberi alert. Batas token dihitung dari token yang sudah diskala dengan token consumption rate model.

```bash
curl -X POST http://localhost:8080/v1/budgets \
  -H "Authorization: Bearer <jwt-dashboard>" \
  -H "Content-Type: application/json" \
  -d '{
    "scope_kind": "api_key",
    "scope_id": "<id-key>",
    "budget_spend": 25,
    "period": "monthly",
    "alert_pct": 80,
    "hard_cutoff": true
  }'
```

Pemakaian berjalan dilihat lewat `GET /v1/budgets/status` atau halaman **Quota Tracker** — termasuk persentase spend dan token terhadap batas. Budget yang sedang libur kerja bisa dijeda lewat **Quota Tracker** tanpa dihapus.

## Harga model

Biaya dihitung dari tabel harga per juta token: input, output, cache read, dan cache write. Harga bawaan diambil dari snapshot provider, dan bisa ditimpa per model lewat _pricing overrides_ (halaman **Plans** atau API `model-pricing-overrides`).

Model yang tidak punya harga dihitung nol — kalau angka spend di **Usage** terasa terlalu kecil, cek dulu apakah model yang dipakai sudah punya harga.
