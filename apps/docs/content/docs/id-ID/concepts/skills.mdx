## Skills

Skill adalah potongan prompt yang dikelola dari dashboard dan bisa dipanggil ulang — cara rapi memusatkan instruksi yang berulang (gaya jawaban, aturan proyek, format keluaran) tanpa menyebar di banyak klien.

Kelola dari halaman **Skills**: nama, deskripsi, dan isi prompt. Endpoint API-nya sederhana — `GET /v1/skills`, `POST /v1/skills`, `PATCH /v1/skills/:id`, `DELETE /v1/skills/:id`.

Selain mengetik, skill bisa dibuat dengan **mengunggah `SKILL.md`**: `name` dan `description` di frontmatter serta isi file-nya mengisi form pembuatan, jadi prompt-nya bisa diperiksa dulu sebelum disimpan. Formatnya sama dengan format skill disajikan, sehingga skill dari satu instalasi bisa diunggah ke instalasi lain.

Skill bisa dipakai dengan tiga cara:

- **Nyalakan saklarnya** — gateway menambahkan prompt-nya ke system prompt setiap request inference, untuk semua API key, chain, dan model. Skill baru selalu mulai dalam keadaan mati.
- **Pilih di API key** — di tab **Skills** milik sebuah key, pilih skill yang hanya ditambahkan ke request yang memakai key itu (`skill_ids` pada `PATCH /v1/keys/:id`). Skill ini ditambahkan di atas skill yang saklarnya menyala, dan perubahannya berlaku mulai request berikutnya.
- **Salin URL-nya** — tiap skill disajikan sebagai dokumen Markdown di `/skills/<id>/SKILL.md` yang bisa dibaca agent saat dibutuhkan.

Skill yang disuntikkan ditambahkan setelah system prompt dari klien, sesuai urutan pembuatan, masing-masing paling banyak sekali.

<Callout type="warn" title="URL skill bersifat publik">
  Dokumen skill tidak butuh API key agar agent bisa mengambilnya. Id di URL-nya acak, tapi siapa pun
  yang punya link-nya bisa membaca prompt-nya — jangan taruh rahasia di dalam skill.
</Callout>

## Reference skills

Selain skill buatanmu, halaman **Skills** menampilkan _reference skills_: panduan siap-pakai yang menjelaskan ke sebuah agent cara memakai Tera Router — endpoint mana yang dipanggil, autentikasi seperti apa, format body seperti apa.

| Reference skill  | Isinya                                                  |
| ---------------- | ------------------------------------------------------- |
| Tera Router      | Panduan setup dan indeks skill lainnya                  |
| Chat             | `/v1/chat/completions`, `/v1/messages`, `/v1/responses` |
| Image Generation | `/v1/images/generations`                                |
| Text-to-Speech   | `/v1/audio/speech`                                      |
| Speech-to-Text   | `/v1/audio/transcriptions`                              |
| Embeddings       | `/v1/embeddings`                                        |
| Web Search       | `/v1/search`                                            |
| Web Fetch        | `/v1/web/fetch`                                         |

Cara pakainya: klik **Copy** pada skill yang diinginkan, lalu tempel URL-nya ke agent (Claude Code, Cursor, dll). Agent akan membaca panduan itu dan tahu cara bicara dengan router-mu. Tiap panduan mengisi alamat tempat ia diminta, jadi contohnya sesuai dengan router-mu.

Klik ikon **mata** pada skill mana pun — reference maupun custom — untuk membaca `SKILL.md`-nya sebagai Markdown yang sudah dirender di dialog, persis seperti yang diterima agent.

## Media catalog

Halaman **Media** mengelompokkan provider berdasarkan kemampuan non-chat: embeddings, gambar, text-to-speech, speech-to-text, web search, dan web fetch. Daftarnya dibangun dari katalog provider yang sama dengan halaman **Providers** (`GET /v1/media`), jadi setiap kartunya bisa dihubungkan dan dipakai routing. Tiap kartu menunjukkan apakah provider sudah terhubung dan menautkan ke halaman detailnya.
