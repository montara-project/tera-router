Semua endpoint di bawah hidup di server yang sama dengan gateway (default `http://localhost:8080`) dan dipakai oleh dashboard UI. Cocok untuk otomasi dan integrasi.

Referensi endpoint inference ada di bagian [Gateway API](/id-ID/docs/gateway).

## Autentikasi

```bash
# masuk
curl -X POST http://localhost:8080/v1/auth/sign-in \
  -H "Content-Type: application/json" \
  -d '{ "email": "admin@tera.local", "password": "..." }'
```

```json
{
  "data": {
    "uid": "…",
    "email": "admin@tera.local",
    "access_token": "…",
    "refresh_token": "…",
    "expires_in": 3600
  }
}
```

- Access token berlaku 1 jam; refresh token 30 hari dan dirotasi tiap pembaruan.
- Bawa token di header `Authorization: Bearer <access_token>`.
- `POST /v1/auth/sign-out` mencabut semua token sesi.

## Envelope respons

| Bentuk         | Bentuk JSON                                               |
| -------------- | --------------------------------------------------------- |
| Satu resource  | `{"data": …, "metadata": …, "message": …}`                |
| Daftar         | `{"data": […], "metadata": {"total", "offset", "limit"}}` |
| Hapus          | `{"message": "…"}`                                        |
| Error          | `{"message": "…"}`                                        |
| Error validasi | `{"message": "…", "errors": {…}}` (422)                   |

Pagination memakai query `offset` (0-based) dan `limit` (default 10, maks 100).

## Endpoint

### Auth

| Method | Path                | Keterangan             |
| ------ | ------------------- | ---------------------- |
| POST   | `/v1/auth/sign-in`  | Masuk, terima token    |
| POST   | `/v1/auth/refresh`  | Rotasi refresh token   |
| GET    | `/v1/auth/me`       | Profil user saat ini   |
| POST   | `/v1/auth/sign-out` | Cabut semua token sesi |

| DELETE      | `/v1/keys/:id`        | Hapus key                                    |

| ------ | -------------------------------- | ------------------------------------------------------ |
| GET    | `/v1/tunnels/cloudflare`         | `installed`, `running`, dan `url` quick tunnel         |
| POST   | `/v1/tunnels/cloudflare/enable`  | Nyalakan quick tunnel (diingat setelah restart)        |
| POST   | `/v1/tunnels/cloudflare/disable` | Matikan dan biarkan mati                               |

Menyalakan dan mematikan tercatat di audit log. Lihat [Akses jarak jauh](/id-ID/docs/getting-started/remote-access).

### Lainnya

| Method       | Path                           | Keterangan                                       |
| ------------ | ------------------------------ | ------------------------------------------------ |
| GET / PATCH  | `/v1/settings`                 | Settings router (timeout, round-robin, dst.)     |
| GET / POST   | `/v1/skills`                   | Daftar / buat skill                              |
| PATCH        | `/v1/skills/:id`               | Nyalakan/matikan injeksi gateway (`enabled`)     |
| DELETE       | `/v1/skills/:id`               | Hapus skill                                      |

| GET          | `/v1/system/stats`             | Metrik host & proses                             |
| GET          | `/v1/media`                    | Provider katalog per kemampuan non-chat          |
| GET          | `/health`                      | Kesehatan server (tanpa auth)                    |
| POST         | `/v1/backup/database/download` | Snapshot SQLite; perlu password (+ TOTP)         |
| POST         | `/v1/backup/config/export`     | Backup konfigurasi JSON; perlu password (+ TOTP) |

Reveal key dan kedua download backup meminta autentikasi ulang: kirim `"password"`, dan saat autentikasi dua faktor aktif server menjawab `{ "totp_required": true }` sampai kamu mengirim ulang dengan `"otp"`. Password atau kode yang salah dijawab `422` dan dihitung ke blokir IP, sama seperti login gagal.
