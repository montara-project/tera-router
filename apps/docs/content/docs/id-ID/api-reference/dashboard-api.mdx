Semua endpoint di bawah hidup di server yang sama dengan gateway (default `http://localhost:8080`) dan dipakai oleh dashboard UI. Cocok untuk otomasi dan integrasi.

Referensi endpoint inference ada di bagian [Gateway API](/id-ID/docs/gateway).

## Autentikasi

```bash
# masuk
curl -X POST http://localhost:8080/v1/auth/sign-in \
  -H "Content-Type: application/json" \
  -d '{ "email": "admin@tera.local", "password": "..." }'
```

```json
{
  "data": {
    "uid": "…",
    "email": "admin@tera.local",
    "access_token": "…",
    "refresh_token": "…",
    "expires_in": 3600
  }
}
```

- Access token berlaku 1 jam; refresh token 30 hari dan dirotasi tiap pembaruan.
- Bawa token di header `Authorization: Bearer <access_token>`.
- `POST /v1/auth/sign-out` mencabut semua token sesi.

## Envelope respons

| Bentuk         | Bentuk JSON                                               |
| -------------- | --------------------------------------------------------- |
| Satu resource  | `{"data": …, "metadata": …, "message": …}`                |
| Daftar         | `{"data": […], "metadata": {"total", "offset", "limit"}}` |
| Hapus          | `{"message": "…"}`                                        |
| Error          | `{"message": "…"}`                                        |
| Error validasi | `{"message": "…", "errors": {…}}` (422)                   |

Pagination memakai query `offset` (0-based) dan `limit` (default 10, maks 100).

## Endpoint

| POST   | `/v1/auth/sign-in`      | Masuk, terima token                                           |

### Playground

| Method | Path                    | Keterangan                                                                                                                                        |
| ------ | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET    | `/v1/playground/models` | Semua model yang bisa dipanggil playground: model katalog aktif dari provider yang punya akun siap pakai (`provider/model`), lalu alias dan chain |
| POST   | `/v1/playground/chat`   | Chat completion OpenAI yang dirutekan persis seperti traffic gateway (alias, chain, fallback, `stream`)                                           |

Playground memakai JWT dashboard, bukan API key. Pemakaiannya dihitung dan kena budget seperti traffic lain, tapi tidak tercatat atas nama key mana pun. Respons membawa `X-TeraRouter-Provider` dan `X-TeraRouter-Model`, yaitu target tempat request akhirnya mendarat.

Endpoint uji model menerima `{"model", "messages", "stream"}`. Uji yang di-stream dibatasi 2 menit.

### Restricted access

| Method    | Path                    | Keterangan                                      |
| --------- | ----------------------- | ----------------------------------------------- |
| GET / PUT | `/v1/restricted-access` | Periode allowlist saat ini / ganti (seluruhnya) |

Body: `enabled`, `start_date` / `end_date` (`YYYY-MM-DD`, inklusif), `start_time` / `end_time` (`HH:MM`, berulang tiap hari, boleh melewati tengah malam), `timezone` (IANA, kosong berarti UTC) dan `allowed_ips` (alamat atau rentang CIDR). Tanggal atau jam yang kosong berarti sisi itu tidak dibatasi. Selama periode berjalan, semua path kecuali `/health` menjawab `403 forbidden` untuk alamat di luar daftar; loopback selalu lolos. Mengaktifkannya tanpa alamatmu sendiri di daftar akan ditolak.

### Backup & impor

| Method | Path                           | Keterangan                                                                        |
| ------ | ------------------------------ | --------------------------------------------------------------------------------- |
| POST   | `/v1/backup/config/export`     | Backup konfigurasi JSON; perlu password (+ TOTP)                                  |
| POST   | `/v1/backup/config/import`     | Pulihkan backup konfigurasi; tiap tabel di dalamnya menggantikan tabel yang aktif |
| GET    | `/v1/backup/database`          | Info file database yang aktif                                                     |
| POST   | `/v1/backup/database/download` | Snapshot SQLite; perlu password (+ TOTP)                                          |
| POST   | `/v1/backup/database/restore`  | Ganti database dengan file SQLite yang diunggah (field multipart `file`)          |
| POST   | `/v1/import/:source`           | Impor backup JSON `9router` atau `omniroute`                                      |

Kedua restore menulis salinan pengaman database saat ini lebih dulu. Database yang dipulihkan harus lolos cek integritas dan skemanya tidak boleh lebih baru dari server; skema yang lebih lama dimigrasikan naik. Impor bersifat aditif: baris yang sudah ada dipertahankan dan salinan dari backup dilewati, jadi menjalankan impor ulang itu aman.
