## Server (apps/server)

Server membaca variabel-variabel ini dari environment — setiap flag CLI jatuh ke
variabelnya, jadi container tidak butuh daftar argumen. `make run` mengekspor `apps/server/.env`
dan mengoper flag eksplisit, yang tetap menang atas environment.

| Variable                | Default                 | Keterangan                                                                                                                        |
| ----------------------- | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `MACHINE_ID`            | — (wajib)               | ID unik mesin (angka 16-bit, tidak boleh 0)                                                                                       |
| `APP_SECRET`            | — (wajib)               | Menandatangani JWT dan menurunkan kunci enkripsi kredensial; instalasi baru menolak kurang dari 32 karakter                       |
| `PORT`                  | `8080`                  | Port gateway + dashboard API                                                                                                      |
| `ENV`                   | `production`            | `development` mengaktifkan perilaku dev (seed key contoh)                                                                         |
| `DEBUG`                 | `false`                 | `true`/`1` mengaktifkan mode debug                                                                                                |
| `DATABASE_PATH`         | `terarouter.db`         | Lokasi file SQLite                                                                                                                |
| `MIGRATE_ON_BOOT`       | `true`                  | Jalankan migrasi saat start                                                                                                       |
| `SEED_ON_BOOT`          | `true`                  | Seed data awal (role, admin, plan Default)                                                                                        |
| `ADMIN_EMAIL`           | `admin@tera.local`      | Email admin; perubahan mengganti email admin yang ada saat seed berikutnya                                                        |
| `ADMIN_PASSWORD`        | `admin123` (dev)        | Password admin — wajib diset di produksi; perubahan disinkronkan ke admin saat seed berikutnya                                    |
| `ADMIN_TOTP_RESET`      | —                       | Set `true` untuk mematikan two-factor auth admin saat seed berikutnya; hapus lagi setelah login                                   |
| `CORS_ALLOWED_ORIGINS`  | `*`                     | Daftar origin dipisah koma, mis. `http://localhost:5173,http://localhost:3001`                                                    |
| `TRUSTED_PROXIES`       | —                       | IP/CIDR proxy dipisah koma yang dipercaya menyuplai `X-Forwarded-For`                                                             |
| `RATE_LIMIT_EXEMPT_IPS` | —                       | IP klien dipisah koma yang bebas dari rate limit dashboard                                                                        |
| `API_URL`               | — (same origin)         | Base URL API publik yang di-inject ke dashboard dan ditulis ke panduan skill agent; isi untuk split origin atau di belakang proxy |
| `APP_NAME`              | `tera-router-server`    | Nama aplikasi                                                                                                                     |
| `SENTRY_DSN`            | —                       | Aktifkan error tracking bila diisi                                                                                                |
| `OIDC_ISSUER`           | —                       | Base URL issuer OIDC (Pocket ID, Keycloak, …); aktifkan SSO bila ketiganya diisi                                                  |
| `OIDC_CLIENT_ID`        | —                       | Client ID OIDC                                                                                                                    |
| `OIDC_CLIENT_SECRET`    | —                       | Client secret OIDC                                                                                                                |
| `OIDC_PROVIDER_NAME`    | `SSO`                   | Nama provider di tombol login ("Continue with Pocket ID")                                                                         |
| `OIDC_REDIRECT_URL`     | diturunkan              | URL callback yang didaftarkan di provider (`{public URL}/v1/auth/oidc/callback`); isi bila proxy menyembunyikan scheme/host publik  |
| `HEADROOM_URL`          | `http://localhost:8787` | Proxy Headroom default untuk **Settings → Token Saving**; URL yang disimpan di dashboard menimpanya                               |
| `HEADROOM_PROXY_TOKEN`  | —                       | Bearer token untuk proxy Headroom yang di-bind di luar loopback (mis. sidecar compose)                                            |

<Callout type="error" title="APP_SECRET itu kunci rumah">
  Kredensial provider dienkripsi dengan kunci turunan dari `APP_SECRET`. Ganti secret = semua
  kredensial tersimpan tidak terbaca lagi. Ganti hanya sebelum data ada, dan simpan baik-baik. Buat
  dengan `openssl rand -hex 32`: instalasi baru tidak mau start dengan secret di bawah 32 karakter,
  dan instalasi lama hanya mencatat peringatan.
</Callout>

## Target make (apps/server)

| Target                 | Keterangan                                       |
| ---------------------- | ------------------------------------------------ |
| `make run`             | Jalankan API server (baca `.env`)                |
| `make install`         | Siapkan toolchain Go                             |
| `make migrate/up`      | Jalankan migrasi                                 |
| `make migrate/down`    | Rollback migrasi                                 |
| `make migrate/refresh` | Reset database                                   |
| `make seed`            | Seed data produksi                               |
| `make seed/dev`        | Seed key contoh "Dev" (plaintext dicetak sekali) |
| `make test`            | Test                                             |
| `make vet`             | Static analysis                                  |
| `make build/api`       | Build binary server                              |

## Dashboard (apps/web-ui)

| Variable        | Default                 | Keterangan                                                              |
| --------------- | ----------------------- | ----------------------------------------------------------------------- |
| `API_URL`       | `http://localhost:8080` | Alamat API server (hanya dev — di produksi env `API_URL` server menang) |
| `VITE_APP_NAME` | `Tera Router`           | Nama tampilan                                                           |

Dashboard berjalan di port `5173` (`pnpm dev` di `apps/web-ui`).

## Batas bawaan

| Batas                            | Nilai                                          |
| -------------------------------- | ---------------------------------------------- |
| Ukuran body request maksimum     | 32 MiB                                         |
| Read timeout server              | 20 detik                                       |
| Write timeout server             | 3 menit                                        |
| Deadline request unary           | 90 detik                                       |
| Deadline stream                  | 3 menit                                        |
| Heartbeat SSE                    | 15 detik                                       |
| Konkurensi gateway (in-flight)   | 100                                            |
| Rate limit dashboard             | 100 req/menit per IP (`/assets/` dikecualikan) |
| Cache verifikasi key             | 5 menit                                        |
| Retry per request (maks)         | 10                                             |
| Cooldown akun (429 / auth gagal) | 30 detik / 5 menit                             |
